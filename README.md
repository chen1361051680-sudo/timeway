# 时光有路 Timeway

**时光有路——基于百度地图的社区助老时间银行**

时光有路是一款面向社区助老场景的公益时间银行网页应用，以百度地图连接身边的帮扶需求与志愿者。社区或机构发布陪伴聊天、就医协助、手机使用指导等需求，志愿者通过爱心地图发现任务、报名参与，并查看前往服务地点的路线。服务完成并经需求方确认后，系统记录志愿时长、点亮地图上的服务区域，同时积累可兑换社区或机构所提供物品的时间权益。作品通过“发现需求—参与服务—确认时长—权益兑换”的完整流程，让每一次陪伴留下记录，让邻里互助持续发生。

产品采用手机优先设计，仅设置志愿者、需求方两个身份，底部包含爱心地图、服务大厅、时间银行、我的四个入口。

## 快速开始

需要 Node.js 24（含内置 SQLite）。生产运行无第三方框架依赖。

```sh
npm ci
npm run check
npm test
npm run build
npm run dev
```

打开 http://127.0.0.1:4312 。默认 development 环境，数据库自动创建为 `data/development.sqlite`。不需要复制 `.env` 即可本地运行；自定义配置参考 `.env.example`。

本地开发使用 `npm run dev`，修改后端代码时自动重启服务；前端修改后刷新页面即可。电脑和手机联调请使用启动日志中同一端口的本机／局域网地址；如在 `.env` 中设置了 `PORT`，以实际启动地址为准。`npm start` 不会自动加载后端代码变更，适合固定版本运行。

登录页仅保留志愿者、需求方两个入口。点击后打开对应欢迎弹窗，只保留“一键快速登录（模拟账号）”按钮，不展示账号密码、不提供输入框或注册入口。点击后直接进入当前身份的模拟账户。模拟登录仅开放于开发／测试环境，生产环境关闭。

可选 `npm run seed`：只准备“模拟志愿者”和“模拟需求方”两个账号，不生成默认需求、兑换服务、成果或时间余额。未 seed 时，首次模拟登录只准备所选身份的固定账号；重复登录或执行 seed 复用账号并保留已有资料和业务记录。服务大厅、爱心地图和时间银行中的业务内容必须来自需求方实际发布及后续参与、核实流程。

## 已实现的业务

- 一键快速登录（模拟账号）、固定角色、资料、会话、显示设置、站内业务消息、服务前提醒和反馈。任务留言／评价与服务材料功能已移除。
- 需求公开预览、发布、编辑、暂停、取消、报名、确认参与、退出、变更协商、签到与人工补录。
- 服务记录提交、有效分钟核实、部分完成、异议、更正和撤销；时长入账与地图成果从有效记录计算。
- 机构分账、可用／待确认／占用／异议冻结／已使用时间、流水；兑换项目、预约、改约、取消、追加协商、部分履约、申请人确认结算与双方确认更正。
- 固定约 500 米网格、多人同一服务事件去重、同网格持续服务统计、个人／机构足迹、区域成果、匿名分享卡、地点补充及更正后重算。
- SQLite 事务、唯一财务流水引用、HTTP 幂等键、名额和余额校验、时间冲突校验、跨角色和跨机构权限隔离。

七个共用页面通过 hash 路由组织，其他动作复用弹窗。需求方与志愿者共用同一后端和 SQLite，发布、参与、确认与兑换的数据相互关联。

## 外部服务状态

- 百度地图：配置浏览器 AK 后提供真实底图、任务标记、地点搜索与浏览器定位。任务详情支持步行、公交、驾车路线查询和百度地图导航链接。配置方式见 `docs/外部服务接入清单.md`，路线功能见 `docs/任务路线说明.md`。
- 短信：提供 HTTPS webhook 接入方式，需要配置短信供应商及服务端凭据；生产环境关闭开发验证码与模拟登录入口。
- 兑换封面：开发与测试环境分别保存到本地数据目录，生产环境使用腾讯云 COS，需要配置存储桶、区域与服务端凭据。

```sh

```

本机已安装 Chrome 时，可在 PowerShell 使用 `$env:PLAYWRIGHT_CHANNEL='chrome'` 后运行 `npm run test:ui`。浏览器测试启动独立 test 环境内存数据库，包含两端完整链路，不使用生产账号。截图输出 `tmp/ui-checks`，不进入 Git。

## 结构

- `server.mjs`：同源静态资源、API 和安全响应头；生产环境仅监听 127.0.0.1，开发环境支持局域网手机调试。
- `src/store.mjs`：SQLite 初始化迁移、事务、环境和 schema 版本保护。
- `src/domain.mjs`：帮扶、时间账户、兑换、成果与通知业务。
- `src/http.mjs`、`src/auth.mjs`：路由、模拟认证、会话、CSRF、幂等请求、私密附件。
- `src/adapters.mjs`、`src/routing.mjs`：外部服务边界与往返时间预算规则。
- `public`：原生 ES Modules 手机网页，无运行时 UI 框架。
- `scripts`：检查、静态资源打包、开发演示数据、SQLite 在线一致性备份。
- `test`、`e2e`：业务／HTTP 测试及真实浏览器联调。

`npm run build` 校验源文件并打包 `dist/public` 与版本清单；原生服务器直接读取 `public`，无需转译。`dist` 是可重建输出，不进入 Git。

## 数据与部署

SQLite 按环境隔离，整数分钟记账；会话、OTP 和核心账务使用独立表，业务实体保存在带 JSON 有效性校验的 SQLite 实体表中。结构版本使用 `PRAGMA user_version`，禁止旧代码覆盖新版本数据库。时间记录更正产生差额流水，不覆盖旧账。

`.env`、数据库、附件、备份、密钥均在 Git 忽略范围。`npm run backup` 使用 SQLite 在线备份 API（包含已提交 WAL 数据），生成后执行完整性检查。

项目域名为 `timeway.chhwork.cn`。SQLite 定时备份、目录权限和版本管理说明见 `docs/部署与运维说明.md`。
