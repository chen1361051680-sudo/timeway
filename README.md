# 时光有路 Timeway

以百度地图 API / SDK 为核心的公益时间银行产品：发布需求、参与助老服务、确认有效时长、点亮爱心地图，并通过时间权益兑换机构提供的服务。

## 产品结构

- **爱心地图**：查看已帮助片区、发现附近需求、回顾个人足迹。
- **服务大厅**：发现需求、报名参与、跟进服务及核实结果。
- **时间银行**：查看账户和收支明细、申请兑换、跟进兑换预约。
- **我的**：维护个人或机构资料，查看贡献摘要和常用入口。

仅设置志愿者与需求方两类角色。
