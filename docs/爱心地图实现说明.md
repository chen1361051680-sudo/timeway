# 爱心地图页面实现说明

以当前对话提供的 UI 设计图及后续调整为视觉依据。按用户最新要求，移除顶部产品标志和志愿者插画横幅，保留搜索框、大家的爱心／我的足迹切换。

## 已实现

- 杭州主题插画、珊瑚橙成果标记、蓝色需求标记、地区搜索、消息入口、范围切换、待帮助开关、筛选和定位降级入口。
- 地图下方按最新参考图使用横向圆角成果横幅：圆形志愿者插画、文案“让善意随时发生”、三列真实成果及右侧箭头；不再单独重复展示成果数据栏。横幅上方把手及标题区域支持上下拖动，松手自动停靠：收起只保留成果，展开显示需求及可独立滚动的列表。右侧箭头、把手点击和键盘上下键也可切换。地图固定在面板后方，拖动不重建地图或更改地图视角；需求方展示对应机构数据。
- 点选需求或点亮地区更新同一张卡片；收起再展开保留选择；详情返回保留地区与需求。全部区域和需求从“区域列表”进入。
- 过滤已截止、已满、暂停及已参与的需求；默认优先展示已确认服务。需求方展示本机构成果、待办计数和发布入口。
- 筛选留在地图页，搜索与地区条件分别保留，查看更多带入服务大厅。未知路线不当作零耗时，启用距离或含往返预算时不会产生虚假推荐。
- 全站 MiSans 400／600 两种字体已纳入站内静态资源和构建。

## 接入边界

百度 JavaScript API 4.0 已接入。配置 `MAP_PROVIDER=baidu` 与浏览器 AK 后显示真实底图，支持拖动、缩放、城市切换、地点搜索、公开需求与已点亮网格、浏览器定位以及页面返回时保留地图视角。地图标记来自公开网格或粗粒度区域，禁止使用私人门牌。仅底图实际加载后结束加载提示，SDK 失败与超时提供重试及区域列表入口。

首次进入爱心地图，百度地图初始化完成后自动申请浏览器定位权限，每次页面加载只自动尝试一次，切换页面与筛选不重复申请。期间显示“定位中…”并阻止重复请求；成功后显示“城市·区县”，移动到当前位置并刷新对应区域需求，保留服务类型等筛选。拒绝或定位失败后保留页面浏览能力，无已选地区时显示“点击定位”；点击可重新定位或手动输入城市、区县。右侧定位按钮继续用于回到当前位置。精确坐标只用于地图定位与坐标转换，不写入账号地址或数据库。

未配置地图时继续使用明确标注的插画示意。路线服务仍未接通，不会把设计图中的“预计 15 分钟”或未知路线写成真实结果。定位失败或拒绝时可以手动搜索，不模拟用户位置。

点亮、时长和服务次数来自 SQLite 已确认记录；设计稿中的 12／28／96 不写入业务数据。空账户显示零和首次帮助提示。所有 UI 验证数据仅存在测试进程的内存 SQLite 中。

## 文件与验证

- 页面组件：`public/map-ui.js`；独立样式：`public/map.css`。
- 百度 SDK 生命周期与交互：`public/baidu-map.js`；公开网格几何：`public/map-geo.js`。
- 底部面板手势、停靠及列表滚动：`public/map-sheet.js`。
- 状态与接口联动：`public/app.js`；静态资源白名单：`server.mjs`；打包：`scripts/build.mjs`。
- `npm run test:map`：覆盖空状态、真实核实成果、五种宽度、选择、筛选、图层、收起、详情、待办和已确认安排。
- `npm run test:ui`：原有两角色报名、核实、入账、兑换全流程回归。
- `node e2e/baidu-map.mjs`：需本地浏览器 AK，验证真实瓦片、网格转换、标记、搜索、缩放、返回保留、测试坐标定位、权限拒绝及加载失败降级；使用内存 SQLite，不改开发或生产业务数据。
- `npm test`、`npm run check`、`npm run build`：业务规则、语法和产物检查。
- 本地截图位于 `tmp/map-checks/`，使用明确隔离的测试数据，非生产公益成果。
