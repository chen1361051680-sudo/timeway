# 服务完成确认

志愿者点击“提交服务记录”后，弹窗展示爱心插画、感谢文案、服务名称和核实说明，提供“取消”“确认完成”两个按钮。

志愿者点击“确认完成”后，服务状态显示“待机构确认”。机构核实完成后，状态显示“已完成”，同步确认服务时长及对应成果。

确认完成调用报名接口的 `complete` 操作。已确认参与的志愿者可直接确认完成，服务端按约定服务安排生成待核实记录，允许在计划开始前提交。未确认参与、他人操作及待确认的安排变更受到权限与状态检查约束。重复提交沿用已有记录；最终时长由需求方核实后入账。已有异议记录再次提交时保留原记录内容和时间。

验证命令：`node e2e/service-completion.mjs`、`npm run build`。浏览器测试使用独立 SQLite 内存库和真实本地 HTTP 服务，检查三个屏幕宽度、图片加载、两个按钮、取消、提交、重复请求及核实入账。
