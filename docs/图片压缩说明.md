# 手机图片压缩说明

页面内置插画改用 WebP，保留 PNG 原图供后续设计修改。原图仍在原路径，浏览器正常页面不再请求这些 PNG。分享成果卡的动态 PNG 下载不受影响。

## 尺寸与质量

- 全宽背景上限 1040 像素宽，配合最大 520 CSS 像素的手机页面，保留约两倍像素密度；小于目标的原图不放大。
- 登录标识上限 396 像素，需求方标识和头像上限 300 像素，服务列表配图上限 384 像素。
- 三张参考图被 CSS 作为局部配图使用，保留原尺寸和比例，避免取图位置偏移。
- WebP 使用质量 85，保留透明通道，不裁剪原图。CSS 显示尺寸和页面布局保持不变。

## 体积对比

| 资源 | 原始大小 | WebP 大小 |
| --- | ---: | ---: |
| 全部 19 张内置图片合计 | 32.78 MiB | 1.06 MiB |
| 登录背景 | 2114 KiB | 111 KiB |
| 登录标识 | 1347 KiB | 24 KiB |
| 服务列表配图（单张） | 1807–2560 KiB | 21–52 KiB |

合计减少 96.8%。这是资源文件的总量对比，不代表首屏一定加载全部图片，也不代表整页提速 96.8%；字体、网络和地图接口仍影响实际加载时间。

## 重新生成

本地安装支持 WebP 的 Pillow 后执行 `python scripts/optimize-images.py`。脚本从 PNG 原图生成同路径 WebP，按用途缩放并检查尺寸和透明通道。Python/Pillow 仅供维护使用，运行和部署应用不需要安装。

新增图片需要在脚本中明确用途和尺寸，生成后将页面引用指向 WebP。WebP 已在静态资源 MIME 和构建清单支持范围内。
