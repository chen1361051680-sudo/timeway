# 外部服务接入清单

本地业务与外部平台的接入状态如下。生产、开发、测试数据库通过路径和库内环境标记双重隔离。

## 百度地图

设置 `MAP_PROVIDER=baidu` 和 `BAIDU_MAP_BROWSER_AK` 后，爱心地图启用百度 JavaScript API 4.0，支持真实底图、拖动缩放、公开位置标记、地点搜索、城市切换与浏览器定位。浏览器 AK 通过 `/api/config` 提供给 SDK，应在百度控制台选择浏览器类型并配置 Referer 白名单，本地可填 `127.0.0.1,localhost`，正式域名为 `timeway.chhwork.cn`。修改 `.env` 后重启服务。`MAP_PROVIDER=manual` 或未填 AK 时保留明确标注的插画示意及区域列表。

底图、地点搜索和坐标转换使用浏览器 AK 即可；`BAIDU_MAP_SERVER_AK` 仍为后续服务端路线适配预留，不会发送到浏览器。爱心地图进入页面时申请浏览器定位，也可点击定位按钮重新获取。失败或拒绝权限时提示原因，不使用 IP 位置冒充准确定位，不将当前位置写入业务数据库。

志愿者服务大厅提供服务类型、预约日期、服务时长筛选，服务按开始时间排列。路线里程和到达时间由任务详情的路线功能提供。

替换位置：`src/adapters.mjs` 的地图／路线适配和 `public/app.js` 的 `mapPage`、地点表单、`route` 操作。适配结果统一为 `{provider, minutes, returnMinutes, distance}`，时间单位分钟，距离单位公里，无法计算为 `null`。`src/routing.mjs` 已实现预约占用时间＋去程＋返程＋缓冲的可用时间判断，并测试缺失结果不计零。真实路由请求需先获取或缓存结果，再调用纯业务规则；不得在 SQLite 写事务中等待网络。

固定网格在 `src/common.mjs` 的 `cellFor` 计算，坐标合同为 WGS84。`public/map-geo.js` 仅从公开的 500 米网格还原中心与边界，`public/baidu-map.js` 调用百度 Convertor 转为 BD-09 后渲染；无网格的需求只解析公开区域名。公共接口不返回私人坐标与门牌。真实路线、到达时间与依赖路线结果的距离排序仍待接入，未知耗时不会显示成真实预计结果。

安全策略仅在启用百度时允许所需 SDK 域名和动态模块执行。本地 HTTP 页面兼容 SDK worker 的 HTTP 瓦片请求，生产响应不开放这些 HTTP 例外；百度 Logo、版权与比例尺保留显示。`node e2e/baidu-map.mjs` 使用本地浏览器 AK 运行真实联网检查，数据库始终为测试内存库，定位使用测试坐标。

## 短信

`SMS_PROVIDER=development` 仅在 development／test 返回页面可见的模拟验证码，生产环境即使错误配置为 development 也拒绝发送。验证码五分钟有效，60 秒重发间隔，最多五次校验尝试，消费后不可重放。生产会话 Cookie 为 HttpOnly、SameSite=Lax、Secure。

真实接入边界支持 `SMS_PROVIDER=webhook`、`SMS_WEBHOOK_URL`（HTTPS）、`SMS_WEBHOOK_TOKEN`。服务端 POST `{phone, code, expiresIn:300}`，Authorization 为 Bearer token；仅将成功响应视为发送成功。需要供应商账号、签名与短信模板及转发适配，不能把 webhook 配置存在描述为已经成功发送。适配位置 `src/adapters.mjs`，业务位置 `src/auth.mjs`。

没有密码、万能验证码、生产快捷登录或隐藏测试账号。

## 历史服务材料

“服务材料”功能已移除，上传、列表和下载接口均停用。原有 `data/<environment>-uploads` 文件及 SQLite 附件元数据保留，不随功能移除而删除。

文字服务记录、核实和异议继续使用现有流程，无需附件。

如已有历史 COS 对象，按现有持久化与备份规则保留。

## 兑换封面

需求方通过 `/api/offer-covers` 上传 JPG、PNG 或 WebP 静态图片，最大 3 MB、2500 万像素。服务端使用 Sharp 解码，将图片转换为最长边不超过 1600 像素的 WebP，并移除图片元数据。SQLite 保存图片所属机构和存储位置，未发布图片仅上传机构可访问；发布后，登录用户可以在兑换列表和详情中查看。

development 和 test 分别保存至 `data/development-offer-covers` 与 `data/test-offer-covers`。自动检查使用 `.cache` 下的独立数据库及图片目录。production 使用腾讯云 COS SDK，需要 `COS_BUCKET`、`COS_REGION`、`COS_SECRET_ID` 和 `COS_SECRET_KEY`；凭据仅由服务端读取，缺少配置时上传返回明确错误。图片通过站内接口读取，COS 存储桶无需公开读取权限。本地已验证真实图片上传与保存，生产 COS 联调需要正式配置。

## 通知

站内通知已真实持久化。打开应用后会生成已确认服务／兑换开始前 24 小时的提醒，消息中心标记已读并跳转最新任务状态。业务状态通知不受显示提醒偏好影响。短信推送和浏览器离线推送不在已接通能力内，后续可复用站内通知记录，避免重复发送。
