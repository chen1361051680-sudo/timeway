# 正式网址的手机测试模式

用户于 2026-09-13 明确要求在正式网址开放模拟账号，供手机测试使用。保留 NODE_ENV=production 的 HTTPS、Secure Cookie 和安全响应头，通过显式开关启用模拟认证。

- `DEMO_MODE=true`：允许两个固定模拟账号登录。
- `DEMO_DATABASE_PATH=/www/wwwroot/timeway/data/demo.sqlite`：测试库，环境标记为 demo。与生产库路径相同时拒绝启动，也拒绝复用带生产环境标记的数据库。
- 原 `DATABASE_PATH` 和 production.sqlite 保留，不写入测试数据。
- 志愿者账号 volunteer，需求方账号 requester，共用公开测试密码 timeway123。页面提供一键登录，模拟账号是共享测试身份，请仅使用测试资料。
- 页面顶部明确显示手机测试状态。每日 SQLite 备份在开启模式时备份 demo 数据库。
- 正式启用真实用户前将 `DEMO_MODE=false`，应用恢复原生产库。不会删除手机测试记录，也不会自动导入生产。

该显式用户要求优先于旧文档“生产一律禁用模拟账号”的默认约定；未设置开关的生产服务仍然默认禁用模拟认证。
