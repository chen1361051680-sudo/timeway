# 正式网址的手机测试模式

用户于 2026-09-13 明确要求在正式网址开放模拟账号，供手机测试使用。保留 NODE_ENV=production 的 HTTPS、Secure Cookie 和安全响应头，通过显式开关启用模拟认证。

- `DEMO_MODE=true`：允许两个固定模拟账号登录。
- 用户随后明确要求与当前开发数据库一致，不另建 demo 库。使用 `DATABASE_PATH=/www/wwwroot/timeway/data/development.sqlite`，通过 SQLite 在线一致性备份同步本地当前开发数据，保留其 development 环境标记。
- 原 production.sqlite 与之前的 demo.sqlite 均保留，不覆盖或删除；当前测试只使用 development.sqlite。原 DEMO_DATABASE_PATH 不再生效。
- 志愿者账号 volunteer，需求方账号 requester，共用公开测试密码 timeway123。页面提供一键登录，模拟账号是共享测试身份，请仅使用测试资料。
- 页面顶部明确显示手机测试状态。每日 SQLite 备份在开启模式时备份 development 数据库。
- 正式启用真实用户前将 `DEMO_MODE=false` 并恢复生产 DATABASE_PATH。不会删除手机测试记录，也不会自动导入生产。
- 本次同步是线上数据副本，本地与服务器后续修改不会自动互通；再次同步前须先核对并保留服务器新增数据。

该显式用户要求优先于旧文档“生产一律禁用模拟账号”的默认约定；未设置开关的生产服务仍然默认禁用模拟认证。
