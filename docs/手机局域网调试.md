# 手机局域网调试

手机和电脑连接同一 Wi-Fi，电脑在项目目录运行 `npm start`。开发模式默认监听 `0.0.0.0:4312`，启动日志会列出局域网访问地址。手机打开电脑 WLAN 网卡对应的 HTTP 地址即可；电脑本机仍可使用 `http://127.0.0.1:4312`。

使用当前 `.env` 配置的开发 SQLite 数据库，不创建或同步另一份数据库。前端修改后刷新页面，服务端修改后重启开发进程。电脑必须保持开机和服务运行；切换网络后局域网 IP 可能改变。

## 配置

- `NODE_ENV=development`：默认允许局域网访问。
- `BIND_HOST=127.0.0.1`：可选，恢复仅本机访问；也可指定某个本机 IP。
- `PORT=4312`：继续使用原有端口。
- `PUBLIC_ORIGIN`：开发模式仍接受配置的来源，同时接受与当前请求 Host 相同的 HTTP 来源，电脑与手机均可登录和提交；不允许任意跨站来源。
- `NODE_ENV=production`：始终监听 `127.0.0.1`，包括开启 `DEMO_MODE` 时。正式环境来源校验、Secure Cookie 和百度地图 CSP HTTPS 升级策略不变。

## 网络与地图

若 Windows 防火墙拦截，只需允许当前局域网到本项目 TCP 端口，不需要关闭整个防火墙，也不需要路由器公网端口映射。访客 Wi-Fi 或路由器的设备隔离可能阻止手机访问电脑。

开发 HTTP 页面不强制升级站内资源至 HTTPS，避免手机访问局域网 IP 时脚本和图片加载失败。普通手机 HTTP 页面通常不支持浏览器 GPS 定位；使用手动地址、地图选点，或在正式 HTTPS 网站验证设备定位。百度浏览器 AK 的 Referer 白名单需要允许当前局域网 IP；若地图受限，页面保留手动地址入口。

请求幂等键兼容普通 HTTP：浏览器没有 `crypto.randomUUID` 时使用 `crypto.getRandomValues` 生成 UUID，避免登录和发布按钮报错，不使用弱随机数替代。
