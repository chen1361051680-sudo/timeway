# 发布服务优化

发布页复用现有 `/#publish/help`、`/#publish/redeem` 和 `/#publish/:id` 路由、SQLite 实体、权限与安排变更确认流程。

## 表单

- 发布页仅保留“需求内容／服务安排”两块，全部核心信息仍在页面内。类型选择放在内容区右上角，标题和正文直接填写；开始时间、时长与志愿者人数放在同一区。删除重复标题、必填提示、大块说明及独立的补充设置面板，保留小型线性图标和 MiSans 字体。
- 机构联系人、已维护的联系电话和常用地址自动带入。地点直接展示并可点击选址；报名截止和联系人以当前值摘要展示，点击所在行原位展开修改，关闭后保留输入。错误会自动展开对应行并定位字段。保留手动地址入口，默认不展开输入框。
- 新需求默认明日 09:00 开始，选择“服务多久”后自动计算结束时间，提供半小时至四小时常用选项；选择“其他时长”后在原位填写小时与分钟；支持 1 分钟至 24 小时，分钟部分为 0–59 的整数。报名截止摘要同时显示日期和规则，常用规则随开始时间联动，仅选择自定义时显示日期输入。编辑已有任意时段会保留原值。
- 不提供结束时间、预计受助人数、服务要求、不计入时长、受助对象和集合到达说明的输入项；编辑历史需求时，未提交的旧字段保留原记录。
- 新帮扶需求的计划时长按所选服务时长计算；兑换使用小时与分钟填写。编辑历史需求且没有改变服务安排时保留原计划时长与已有私有说明，避免仅修改地址或联系人时改动旧记录。预计结束时间不代表实际服务已经核实，预计时长不直接入账。
- 固定操作栏提供预览并发布。键盘默认提交进入预览。预览只显示公开区域、服务内容、时段与名额，私人门牌、对象和联系电话不公开。
- 校验错误显示在字段旁并展开所在设置、定位到字段；修改字段或关联时间后清除过期错误提示。已填写内容不会因验证或网络失败清空。同一份提交重试复用幂等键，修改内容后产生新键。
- 编辑页继续带入原数据，预览可展开仅本人可见的修改对照。既有参与者需要确认的核心变更仍走原流程；新发布时检查未来日期。
- 新需求发布成功后直接进入服务大厅的“已发布需求”，重置为“全部”、刷新列表并回到顶部，本次刚发布的需求优先展示。编辑保存及兑换服务发布继续进入对应详情页。

## 保存稳定性

- 保存期间展示进度，锁定表单和弹层按钮，拦截连点、重复提交及页内离开，避免保存中的内容被修改。
- 发布请求均设置 15 秒超时；超时或连接中断后恢复操作，保留全部输入并提示重试，不在后台自动循环提交。
- 同一账号、同一需求、同一份内容重试复用请求标识。沿用服务端 SQLite 事务和幂等记录，即使服务器已保存、客户端响应丢失，重试也返回原需求；改动内容后生成新标识。

草稿功能已移除：不提供保存、筛选、继续编辑和复制为草稿入口；API 不再接受草稿状态。应用启动时仅清理旧草稿实体及旧草稿幂等响应，保留已发布需求、服务记录和审计历史。

## 真实地点

- 新增共用选址弹层：地区范围、地点搜索、当前位置、点击地图、拖动选点、文字地址核对、确认回填。使用已有百度 SDK 加载器，不抢占首页地图实例。
- 本地 `.env` 中已有浏览器端百度配置，预览通过显式传入浏览器配置接入真实服务。未读取或公开服务端密钥。
- 用户主动点击当前位置才请求浏览器定位；权限拒绝、超时、无匹配结果、地图不可用时保留手动地址入口。
- 搜索与逆地址解析使用递增请求标识，迟到结果不会覆盖后选地点；取消或关闭弹层不会回填。主表单仅展示选址摘要，地图在选址弹层中显示；手动地址默认折叠，从选址弹层进入时自动展开并聚焦。
- 选址原始百度点保存在私有 `place` 中，服务端验证和白名单提取。现有 `lat/lng/cell` 继续使用原 WGS84 网格口径，通过固定版本 `coordtransform@2.1.2` 做近似反变换，避免重复把百度坐标当作 GPS 坐标。原始点用于再次编辑与精确地图标记，近似反变换不用于声称签到精度。
- `place` 与私人地址、电话、坐标一样仅对必要参与者开放；公开任务视图移除它，公开地图仍使用概略网格。
- 手动修改文字地址会清除旧选址和旧坐标，避免新地址与旧地图位置不一致。具体门牌可在详细地址中填写。单纯文本地址可发布，未确认的位置不生成地图成果。
- 成果地点更正清除旧选址元数据，避免以后编辑时重新应用过期坐标。

相关实现：`public/publish.js`、`public/publish.css`、`public/place-picker.js`、`public/app.js`、`src/place.mjs`、`src/domain.mjs`。

坐标库及许可：[coordtransform（MIT）](https://github.com/wandergis/coordtransform)。百度能力依据：[JavaScript API 官方文档](https://lbsyun.baidu.com/index.php?title=jspopular%2Fguide%2Fintroduction)。

- `npm run build`：语法检查与资源打包通过。
