# 功能与验收对应

## 页面及操作

| 页面 | 志愿者 | 需求方 |
| --- | --- | --- |
| 登录／注册 | 手机验证码、选志愿者、资料补全 | 手机验证码、选需求方、机构资料补全 |
| 爱心地图 | 共同区域、个人足迹、需求、摘要、匿名分享 | 共同区域、本机构成果、待办、发布入口 |
| 服务大厅 | 发现需求／我参与的、关键词与类型／日期／时长筛选、状态与详情 | 已发布需求／待办、状态筛选、发布与管理 |
| 任务详情 | 报名、退出、变更确认、地址与联系、提交服务记录、异议 | 确认／不通过报名、编辑／复制／暂停／取消、核实／更正／撤销、地点补充 |
| 发布表单 | 无权限 | 帮扶／兑换共用；公开预览、私人地址、坐标、时间、人数、联系人 |
| 时间银行 | 分机构余额与冻结／占用、流水、可兑换服务、我的兑换 | 发放流水、兑换项目、兑换预约与待处理事项 |
| 我的 | 资料、技能、足迹、历史、消息、设置、反馈、退出 | 机构资料、联系人、成果、历史、消息、设置、反馈、退出 |

预约详情复用详情结构：双方改约、取消、协商追加、机构履约记录、申请人确认／异议、部分完成释放剩余时间、更正退款须另一方确认。操作历史关联原任务或预约；留言、评价和材料功能已移除。

## 数据与状态规则

- 只采用已核实的有效分钟；未开始的服务不可提前提交。人工补录须说明，休息不入账，帮助多人不倍增个人时长。
- 名额确认与权益变更在 SQLite 即时写事务中执行。并发最后一个名额只能一人成功。报名和财务引用唯一，重复确认不会多入账。
- 已确认安排核心变更等相关人员确认后生效；退出释放名额。取消已发生服务仍可提交真实部分核实。
- 兑换使用对应机构权益，占用即从可用余额扣除；未完成取消释放。实际结果确认后只扣实际值；增加占用先经申请人同意。
- 争议成果暂不点亮，已入账争议金额冻结新增使用。更正以差额流水记录；已花费金额被撤销时显示待补足金额，不产生可用负数或额外权益。
- 网格约 500 米，多人同一次活动公共地图只记一次；同网格持续服务不重复增加地点。只有至少一位受助者、正有效时长的核实结果才点亮，撤销重新计算。
- 兑换不减少志愿贡献，作为受助者的兑换不会产生个人志愿奖励；机构完成兑换可形成公共帮扶事件。
- 开发文件仅相关参与者可访问。未确认报名的人无法读取私密门牌、受助对象和材料。生产缺少 COS 时不开放上传。

## 自动验证

`npm test` 覆盖完整核心链路、部分兑换、幂等、越权、变更同意／退出、团队与网格去重、地点补充、取消补录、重新报名、改约、追加、争议、透支更正、多机构账户、SQLite 重开、环境隔离、备份 WAL 完整性、schema 降级保护、HTTP 并发、已移除接口拒绝访问与旧数据保留、验证码次数／冷却／消费、CSRF、站点文件隔离、往返时间预算。

`npm run test:ui` 用独立 test 内存数据库与两个浏览器会话跑完整链路：注册与角色资料、发布、隐私校验、报名、确认、服务补录、核实入账、地图成果、部分兑换与结算、刷新持久化、资料修改、四个导航页面及手机横向溢出检测。截图保存在 `tmp/ui-checks`。测试中仅对独立测试数据调整预约时间，产品没有修改服务器时钟的开发接口。

`npm run build` 执行源码语法检查并生成静态资源包。浏览器与业务测试均不连接生产环境。
