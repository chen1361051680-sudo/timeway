# 需求方时间银行与我的

按用户提供的两张参考图还原需求方 `/#bank` 与 `/#profile`，实现位于 `public/requester-account.js`、`public/requester-account.css`，由现有 `public/app.js` 按角色加载。

## 页面与交互

- 时间银行：天空城市页头、消息铃铛、机构信息、三个统计卡片、统计说明、下划线标签、日期与任务筛选、带插画头像的发放记录。
- “已确认发放时长”和“查看记录”打开全部发放记录；“待核实时长”筛选待核实记录；“待处理兑换”筛选需要本机构处理的预约。
- 点击记录打开共用任务详情，并定位到对应志愿者的具体服务记录。返回保留筛选；日期筛选按上海时区处理，支持取消、空结果与重置。
- “兑换服务”显示本机构实际发布项目，复用发布表单、详情与编辑流程；“兑换预约”支持状态和待处理筛选，复用预约安排、改约、履约及更正流程。
- 我的：湖景宝塔页头、设置、机构标识、身份与地区、编辑资料、三项机构成果、四个业务入口和渐隐湖景页尾。
- 我的页面间距与志愿者页统一：页头高度和标题留白、卡片间距及内边距、菜单行上下留白、图标占位、标题说明间距。窄屏保持必要的页头高度，内容可自然换行和滚动。
- 机构成果跳转本机构地图；已完成帮扶跳转服务大厅的已完成筛选；累计确认发放时长跳转发放记录；帮扶记录、兑换预约和业务消息使用已有入口。
- 设置与编辑资料复用现有弹层并保存到真实账户。两页均使用站内 MiSans 400、600，适配窄屏、大字模式和桌面居中的手机布局。
- 保持共用四项底部导航，需求方顶部模拟体验提示保持移除。截图里的系统状态栏和手势条由设备负责显示。

## 数据口径

- 顶部发放时长与个人页累计确认发放时长统一来自 `/api/bank` 的 `issued`；待核实时长来自 `pending`，不展示志愿者余额。
- 发放列表来自本机构帮扶任务的真实服务记录，每名参与者的每条服务记录只出现一次；更正、撤销保留当前记录和状态，不把账本更正或兑换扣减生成重复发放卡片。
- 预约待处理数只包括本机构需要处理的申请、异议、对方提出的改约及更正；本机构发起而等待对方确认的事项不计入。
- 点亮片区和已完成帮扶使用 `/api/map?scope=mine` 的统计。兑换消耗不减少已有志愿贡献。
- 截图中的姓名、286、18、6、320 等示例数字未写入业务代码。测试样例只存在于 `environment: test` 的内存 SQLite，无数据库迁移或生产数据写入。
- 列表只展示必要的公开区域和服务信息，不显示老人姓名、私人门牌、电话或原始服务材料。用户输入经过 HTML 转义。

## 图片素材与生成方式

以下路径均相对项目根目录，构建时包含在静态资源内：

- `public/images/requester-bank-reference.png`：用户银行页原图，仅通过 CSS 显示四张插画头像，作为服务类型示意。
- `public/images/requester-profile-reference.png`：用户个人页原图，仅通过 CSS 显示机构标识。
- `public/images/requester-bank-header.png`：内置 imagegen 工具编辑模式生成的无文字城市背景。
- `public/images/requester-profile-header.png`：内置 imagegen 工具编辑模式生成的无文字湖景背景，同时用于页尾。

页面文字、按钮、统计、卡片和筛选均为真实 HTML/CSS。风景图是按参考图重建的背景，其细节与参考图存在差异。没有使用 CLI 图像生成。
