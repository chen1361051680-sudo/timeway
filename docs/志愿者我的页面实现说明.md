# 志愿者“我的”页面

页面入口为 `/#profile`，按提供的设计图实现湖畔志愿者横幅、个人资料、我的贡献、时间账户、五个记录入口与固定底部导航。网页不模拟手机系统的时间、电量和底部手势条。字体使用站内 MiSans 400／600，最大内容宽度 470px，适配窄屏和大字模式。

## 数据与交互

- 资料读取当前登录身份；编辑称呼、联系电话、常用区域及擅长服务后通过 `/api/profile` 写入 SQLite。联系电话独立保存为 `contactPhone`，不改变登录账号手机号。未保存关闭编辑和设置弹层时提示保留或放弃。
- 点亮地点、服务次数、贡献时长读取 `/api/map?scope=mine`；可用时间汇总 `/api/bank` 的各机构可用余额。兑换占用与扣除不会减少累计贡献；无成果显示 0。
- 爱心足迹与贡献详情进入个人地图；已完成服务与帮扶记录进入服务大厅“我参与的／已完成”。
- 时间账户进入时间银行；贡献时长进入服务入账明细；兑换记录进入“我的兑换”。
- 消息复用通知弹层；帮助含常见问题、协议和持久化意见反馈；设置包含资料、通知偏好、定位说明、文字大小、协议和退出登录。
- 顶图与默认头像是依据参考图生成的独立站内素材，不是用户上传的真实头像。页面不硬编码参考图姓名或成果数字。

## 验证

运行 `npm run test:profile`：使用独立内存 SQLite 验证空账户、真实服务确认后的贡献、兑换占用及释放、资料持久化、关闭未保存资料、大字模式、各入口和反馈。截图输出到 `tmp/ui-checks/profile-*.png`，覆盖 320／390／470／1440 像素宽度。

测试中的林小暖及 12 个地点、28 次服务、96 小时仅由测试库的服务确认流程生成，不写入开发或生产账户。生产发布需另行授权。
