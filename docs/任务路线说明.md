# 任务地点与路线

需求详情中的地图按钮打开“前往服务地点”面板。默认以浏览器当前位置为起点，以需求方发布的详细地点为终点；步行、公交、驾车使用百度 JSAPI 真实路线结果，显示距离、预计耗时和按当前时间计算的到达时间。提供带起终点与出行方式的百度地图导航链接。起点支持手动输入，定位拒绝或查询失败时不生成虚假估算。

按本次产品调整，登录用户无需报名或被确认参与，即可通过任务详情读取服务地址及地点坐标。发布表单和预览说明地点公开。任务列表与公共爱心地图仍展示概略位置；电话、受助对象、附件、参与者资料及待确认的新安排仍保留原访问规则。

公交展示百度实际返回的全部有效方案，提供线路名称、总耗时、换乘次数、步行距离和全程距离。选择方案不重复查询，直接同步路线图、预计到达时间和上下车站、途经站数；地图以灰色虚线表示步行段、蓝色实线表示乘车段。接口只有一套时只展示一套，不构造备选方案。进入百度地图使用起终点重新规划，不承诺沿用当前选中的 SDK 方案，也不显示接口未提供的实时车辆或到站倒计时。

地图选点使用保存的 BD09 坐标；历史 WGS84 坐标及浏览器 GPS 通过百度转换器转换；仅填写文字地址的任务通过百度地理编码定位。当前位置仅在路线面板内使用，不写入 SQLite。慢请求不得覆盖后来选择的出行方式或出发地。

验证命令：`node e2e/task-route.mjs`（隔离数据、SDK 桩）、`node e2e/task-route-live.mjs`（配置本地浏览器 AK 后使用真实百度接口，模拟 GPS）。真实接口检查覆盖步行、公交、驾车；实际定位授权和测量精度仍由用户设备决定。

参考：[百度 JSAPI 4.0 路线规划](https://lbs.baidu.com/docs/jsapi?title=jsapi4%2Fguide%2Flbs%2Froute)、[百度地图 Web 调起协议](https://lbsyun.baidu.com/docs/webapi?title=mapadjustment%2Furi%2Fweb)。
