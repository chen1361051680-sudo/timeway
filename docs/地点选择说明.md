# 发布需求的地点选择

- 顶部将城市选择与地点搜索放在同一行。默认使用已选地点或机构的城市，点击城市名称可修改搜索城市或区县。
- 输入停顿 350 毫秒后查询百度地点建议，中文输入法组字期间暂停查询。结果展示地点名称及地址，支持搜索按钮与键盘提交。
- 空白搜索展示机构地址与最近使用。机构地址用于搜索并核对；最近地点来自当前机构已发布需求及当前页面会话中确认选择的地点，去重后最多展示五条。
- 选择搜索结果或最近地点后，显示地图与完整地址，经过地址核对才启用确认按钮。支持拖动地图、点击地图及当前位置定位。
- 地图与确认按钮在核对阶段显示，搜索阶段主要显示地点列表。地址选择只在点击“确认地点”时写入发布表单。
- 城市切换、重新输入、地图移动、关闭窗口会使先前未完成的查询结果失效。同一窗口内相同搜索复用结果。
- 地图加载失败时显示重新加载入口；搜索失败、无结果及结果列表末尾提供手动填写地址入口。
- 最近地点读取失败时显示说明，保留地点搜索。地址与城市、区县自动回填；关闭选址返回原来触发按钮，手动填写直接进入地址输入框。

验证：`node e2e/place-picker-live.mjs` 使用实际百度服务、Chrome 与独立内存 SQLite，检查查询、选址、真实表单发布、最近地点、城市切换、地图选点、手动填写与手机尺寸；`node --test test/publish.test.mjs` 检查后端地点校验与保存；`npm run build` 检查构建。
