# 地图区域边界

已确认的服务按填写的所属区域汇总；同名区域中的不同服务地点合并展示，帮扶次数累计，参与志愿者去重。重复确认不增加成果次数。历史服务记录和时长账目保留原有数据。

地图使用百度 JavaScript SDK 的 `Boundary` 获取真实行政区域轮廓，支持一个区域包含多段边界。轮廓使用暖橙色边线和浅色填充，选中时增强边线，调整地图视野以显示完整区域。公开标记使用概略位置，公开接口不增加私人地址或精确坐标。

百度公开边界查询覆盖省、市、区县。目前社区、街道、乡镇等缺少对应边界数据时，仅展示概略标记，并提示边界不可用。不会通过上一级行政区或自行绘制形状替代这些区域。社区、街道轮廓需要接入对应的真实边界数据。

同名区域的成功查询在当前页面会话中缓存。查询失败显示重试入口，重新加载后再次查询。区域点亮仅表示该区域已有确认服务。

检查命令：

- `node --test test/baidu-map.test.mjs`
- `node e2e/map-boundaries-live.mjs`：使用 `.env` 中的百度浏览器凭据和独立内存 SQLite，验证实际地点、真实边界、多地点汇总、重复确认、选择区域、手机宽度及缺少街道边界的提示。需要 Chrome。
- `npm run build`
