# 志愿者时间银行

依据《时光有路-功能需求文档》第 7 节、《时光有路-UI页面功能说明》P07 与本次时间银行参考图实现，入口为志愿者底部导航的“时间银行”（`/#bank`）。

## 页面与交互

- 暖色沙漏背景、时间账户卡、机构切换、四项时长、收支明细、双标签、日期/时长/排序筛选、图片服务卡和底部导航。
- 首次进入优先展示已有贡献或待确认时长的机构。切换机构同步筛选账户、兑换项目和本人的预约；可选择全部机构，但权益仍不能跨机构花费。
- 银行筛选独立保存，切换标签、进入详情及返回不受服务大厅筛选影响。
- 可兑换服务展示真实标题、机构、概略地点、说明、预约时段、剩余名额和所需时间；余额不足、满额、截止或调整中明确提示。
- 申请复用兑换详情与弹层，成功后进入已有预约详情。已申请项目提供“查看我的兑换安排”，避免用户重复寻找预约。
- 我的兑换按待确认、待服务、待结果确认、已完成、已取消、改约、异议和未通过筛选；沿用已有改约、取消、确认结果流程。
- 收支明细在弹层中按机构、日期、类型筛选，展示入账、待确认、当前占用、使用、释放、更正和退回，链接到关联服务或预约。
- 可用时间点击展开累计贡献说明，明确兑换不减少志愿贡献。

## 数据与资产

- 使用现有真实 SQLite 账户、服务记录和预约数据；不向开发或生产数据库写入参考图余额。
- 增加取消时释放分钟及时间的记录，无需迁移。部分完成的释放时长由审计前后快照计算，实际扣除部分不计入释放；重复操作不重复显示释放。
- `bankReleases` 仅返回当前身份有权查看的记录摘要，不返回私人联系方式或审计原始材料。
- 字体沿用站内 MiSans Normal 400 / Semibold 600。服务配图复用已有静态资源；顶部图片存于 `public/images/bank-header.png`。布局使用 HTML/CSS，系统状态栏及系统手势条由设备提供。
- 图中机构、服务内容、日期和余额均由业务数据填充。沙漏摄影背景为根据参考风格重新生成，非原始设计源文件的逐像素复制。

## 验证

- `npm run test:bank`：320、390、470、1440 宽度，无横向溢出；覆盖筛选取消/重置、余额不足、明细、状态、取消释放、申请占用、重复申请入口、返回位置、大字模式。
- `node --test test/bank.test.mjs`：真实服务核实生成账户、跨机构余额限制、取消与部分完成释放、重复处理去重、累计贡献不变、机构间权限隔离。
- 视觉与交互样例只使用 `environment: test` 的内存 SQLite；通过真实业务接口生成样例贡献与预约。截图位于 `tmp/ui-checks/bank-*.png`，不参与生产发布。
