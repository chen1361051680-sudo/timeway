# 兑换内容发布

需求方在时间银行的“兑换物品”中点击“新增兑换物品”，进入 `#publish/redeem`。表单使用 MiSans 400 与 600 字重，输入项均有持续可见的标签。

- 物品名称：填写物品本身的名称，例如大米。
- 物品图片：支持上传、更换和删除 JPG、PNG、WebP 图片，大小不超过 3 MB，上传后直接预览。
- 标题：填写列表和详情展示的标题，例如社区爱心好米一袋。
- 规格：填写每份所含物品的规格，例如 5kg／袋，每份 1 袋。
- 兑换所需时长：按小时填写，例如 0.5、1 或 1.5 小时，最多 24 小时。保存时转换为整数分钟，用于账户计算。

提交进入公开预览，确认发布后进入物品详情。机构列表、志愿者列表与详情展示图片、标题、物品名称、规格和以小时显示的所需时长。编辑带入已保存的图片和小时数，已经完成的物品兑换保留当时的名称、规格和扣款金额。

物品发布后持续可申请兑换，机构可编辑内容或点击“删除”。删除后返回时间银行的“兑换物品”，物品从双方的物品列表中移除。已有兑换记录、扣除时长、申请人联系方式与相关图片继续保存，工作人员可以通过兑换记录联系领取。物品不占用服务日程，列表按发布时间或所需时长排列。

志愿者点击“立即兑换”，核对申请人姓名、联系电话与扣除时长，点击“确认兑换”即完成兑换。系统在同一次数据库事务中保存兑换记录、扣除对应机构的时间权益，并向双方发送站内通知。重复提交返回同一条记录，扣款与通知均只执行一次。

志愿者的成功页面和兑换记录显示“请等待工作人员联系你”。需求方的物品详情展示物品信息及编辑、删除操作；兑换记录统一在时间银行的“兑换记录”中查看。记录包含商品信息、扣除时长、兑换时间、申请人姓名与电话，记录详情提供“联系申请人”的拨号入口。记录保留本次申请人的联系方式；公共商品列表仅展示物品信息。

志愿者的“我的兑换”列表显示物品缩略图，兑换记录详情显示物品大图。图片使用兑换时保存的物品图片，机构更换图片或删除物品后仍可查看；图片按照完整比例显示，并随手机页面宽度调整。

已扣除的兑换时长计入账户“已使用”，累计志愿贡献保持原值。物品兑换成功不会直接产生服务成果或点亮地图。

验证命令：

- `node --test test/redeem.test.mjs test/publish.test.mjs`：实际 HTTP、SQLite 和图片处理，检查发布校验、重复发布、编辑、兑换、删除权限、重复删除、兑换记录及账户保存。
- `npm run test:redeem`：使用实际浏览器及隔离的测试服务，检查图片上传、更换、删除、小时输入、物品发布、预览、编辑、直接兑换、扣款、站内通知、双方兑换记录与电话入口，检查 320、390、520 和 1440 像素宽度的页面尺寸。
- `npm run build`：语法检查和静态资源打包。
